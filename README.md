# RackCraft

> Small Data Center Design Package

BOM 기반 랙 실장 · 전력/냉각 구성 · Best Practice 다이어그램 · EVE-NG 시뮬레이션 연동

## Features
- BOM import & rack population
- Power & cooling system configuration
- Best practice diagram generation
- EVE-NG simulation integration

## Tech Stack
- Frontend: React + TypeScript
- Backend: Python (FastAPI)
- Diagram: SVG / React Flow
